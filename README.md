One line of weather for Puddleton, a city that does not exist: showers all day, puddles like small lakes, the ducks have formed a queue — and you are behind the ducks. The program writes the forecast (110 characters) to `/output/entry.txt`, checking it against the competition gate (1–140 characters, not only whitespace) before writing.

## Run it

```sh
node main.ts
```
